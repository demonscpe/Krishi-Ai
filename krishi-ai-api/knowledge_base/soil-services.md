# Soil Services

## Soil Hub Dashboard
Central hub for all soil-related services. Access all soil analysis tools from one place.

## Soil Image Analysis
Upload a photo of soil to analyze:
- Soil type classification
- Color and texture analysis
- Condition assessment
- Instant AI-powered results

Access: Navigate to Soil → Soil Image Analysis

## Soil Test Input
Two ways to input soil test data:
1. Manual entry form - Enter lab test values directly
2. PDF OCR parsing - Upload lab report PDF for auto-fill
Includes validation and review features.

Access: Navigate to Soil → Soil Test Input

## AI Soil Health Analyzer
Get comprehensive soil health assessment:
- Health score from 0-100
- Per-nutrient breakdown cards
- Actionable insights and recommendations
- Nutrient status visualization

Access: Navigate to Soil → Soil Health Analyzer

## Fertilizer Recommendation
Personalized fertilizer plans:
- Crop-specific recommendations
- Exact quantities per acre
- Organic and chemical options
- NPK ratio optimization

Access: Navigate to Soil → Fertilizer Recommendation

## Soil Quality Prediction
Predict:
- Overall soil quality class
- Fertility score from lab parameters
- Crop suitability suggestions

Access: Navigate to Soil → Soil Quality Prediction

## Soil Dashboard
Analytics dashboard tracking:
- Total analyses performed
- Average health scores
- Most common soil types
- Analysis history and records

Access: Navigate to Soil → Soil Dashboard

## Soil Testing Centers
Find nearby soil testing laboratories:
- Search by city name
- Interactive map with markers
- Lab names and Google Maps links
- Covers labs across India

Access: Navigate to Help → Soil Testing Centers

# Tools & Help Services

## Tools Available

### Plant Task Reminder
Set reminders for:
- Irrigation schedules
- Fertilizer application
- Pest inspection
- Harvest timing
- Other farm tasks

Access: Navigate to Tools → Plant Task Reminder

### Task Reminder
General task management for farm operations with customizable notifications.

Access: Navigate to Tools → Task Reminder

### Gemini Chat
AI-powered chat for general agricultural questions and assistance.

Access: Navigate to Tools → Gemini Chat

### Water Management
Smart irrigation and water conservation:
- Irrigation scheduling recommendations
- Rainwater harvesting guidance
- Moisture monitoring tips
- Water conservation techniques

Access: Navigate to Tools → Water Management

### NPK Calculator
Calculate optimal NPK (Nitrogen, Phosphorus, Potassium) fertilizer ratios based on soil test results and crop requirements.

Access: Navigate to Tools → NPK Calculator

### Govt Schemes
Information about Indian government agricultural schemes:
- Subsidies and grants
- Crop insurance programs
- Farmer welfare schemes
- Eligibility criteria and application process

Access: Navigate to Tools → Govt Schemes

### Farmer Benefits
Comprehensive information about farmer benefits including:
- Financial assistance programs
- Training and education
- Market access support
- Technology adoption incentives

Access: Navigate to Tools → Farmer Benefits

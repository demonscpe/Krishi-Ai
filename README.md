## 📌 Project Vision

Krishi-AI is a **complete Smart Agriculture Ecosystem** built as a Final Year Engineering Project. It bridges the gap between traditional farming and modern technology by combining **Web, Mobile, and IoT** into one unified platform — giving every farmer access to AI-driven insights, real-time monitoring, and intelligent crop protection.

---

## 🚨 Problem Statement

- 🌍 Over **60% of India's population** depends on agriculture, yet farmers lack access to modern tools
- 🐗 **Wild animal intrusions** destroy crops worth crores every year with no automated deterrent
- 💧 **Inefficient water usage** leads to crop failure and resource wastage
- 🌿 **Disease outbreaks** go undetected until it's too late, causing massive yield loss
- 📉 Farmers have **no real-time data** on soil health, weather, or market prices

---

## ✅ Solution

Krishi-AI delivers a **three-module integrated ecosystem**:

| Module | Description |
|--------|-------------|
| 🌐 **Web Application** | Full-featured farmer portal with AI recommendations, disease detection, marketplace & admin panel |
| 📱 **Mobile Application** | Android app with offline support, camera-based detection, and multilingual AI assistant |
| 🌾 **IoT Crop Protection** | Raspberry Pi 5 system with YOLOv8 animal detection, smart water management & multi-channel alerts |

## 🌾 IoT Crop Protection System

### *"An Intelligent IoT-Based Crop Protection System with AI-Driven Animal Detection and Water Management"*

This module uses a **Raspberry Pi 5** with a camera and multiple sensors to autonomously protect crops from animal intrusions and manage water resources intelligently.

---

### 🐾 Animal Detection using YOLOv8

Animals detected by the system:

| Animal | Deterrent Sound | Alert Type |
|--------|----------------|------------|
| 🐦 Birds | Bird distress call | SMS + WhatsApp |
| 🐒 Monkeys | Predator sound | SMS + WhatsApp + Call |
| 🐗 Wild Boars | High-frequency alarm | SMS + WhatsApp + Call |
| 🐄 Cows | Cattle deterrent | SMS + Email |
| 🐃 Buffaloes | Cattle deterrent | SMS + Email |
| 🐐 Goats | Goat deterrent | SMS + Email |

**Detection Pipeline:**

```
Camera Feed → YOLOv8 Inference → Animal Identified
     ↓
Capture & Save Image
     ↓
Play Animal-Specific Deterrent Sound
     ↓
Activate Buzzer + Rotate Servo Motor
     ↓
Send WhatsApp + SMS + Email + Phone Call Alert
     ↓
Update Blynk Dashboard + Cloud Log
```

---

### 💧 Smart Water Management

| Sensor | Function |
|--------|---------|
| Soil Moisture Sensor | Detect soil dryness, trigger irrigation |
| Rain Sensor | Detect rainfall, pause irrigation |
| Water Level Sensor | Monitor tank/reservoir water level |
| DHT11/DHT22 | Temperature & humidity for evaporation calc |

**Logic:**
- If soil moisture < threshold AND no rain → activate water pump via relay
- If rain detected → stop irrigation automatically
- If water level low → send low-water alert
- All data streamed live to Blynk dashboard

## 🚀 Installation Guide

### Prerequisites

```bash
Node.js >= 18.x
Python >= 3.10
PostgreSQL >= 14
Android Studio (for mobile app)
Raspberry Pi OS (for IoT)
```

### 1. Clone the Repository

```bash
git clone https://github.com/<your-username>/Krishi-AI.git
cd Krishi-AI
```

### 2. Web Application Setup

```bash
# Backend
cd backend
npm install
cp .env-sample .env        # Fill in your environment variables
npx prisma migrate dev
node server.js

# Frontend (new terminal)
cd frontend
npm install
cp .env.sample .env        # Fill in your environment variables
npm run dev
```

### 3. Python AI APIs Setup

```bash
cd krishi-ai-apis
python -m venv venv
venv\Scripts\activate       # Windows
pip install -r requirements.txt
python app.py
```

### 4. Mobile App Setup

```bash
# Open mobile-app/ in Android Studio
# Configure google-services.json from Firebase Console
# Update API base URL in network/ApiConfig.kt
# Build & Run on emulator or physical device
```

### 5. IoT System Setup (Raspberry Pi)

```bash
# On Raspberry Pi 5
sudo apt update && sudo apt upgrade -y
pip install ultralytics opencv-python RPi.GPIO blynklib twilio

cd iot/
python animal_detection.py
```

### 6. Docker Deployment

```bash
# Full stack with Docker Compose
docker-compose up --build
```
